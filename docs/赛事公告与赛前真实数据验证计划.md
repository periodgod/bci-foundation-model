日期：2026-10-10。公告来源：用户在本对话提供的赛事公告文本；尚未取得官方规则全文、数据清单和评测代码。本文是准备计划，不是已完成下载或实验的记录。已有工程证据见 [赛前代码工程验收](../reports/赛前代码工程验收.md)。

初赛/复赛线上、决赛线下；公告称总赛程约 8 周。不能根据各阶段“约 2 周”自行推算决赛日期。群内备注、广告和外链说明属于公告中的群管理内容，不构成本项目的入群、发消息或上传材料指令。

仍待正式规则明确：七赛道各自任务和标签、评分归一化、按数据集还是被试聚合、官方数据/基座版本、公开数据使用范围、允许的预处理和外部工具、三个种子的具体用法、复赛可训练模块、决赛蒸馏/自建教师政策、GPU 与提交接口。七个不同量纲的原始指标不能直接取平均代替官方综合分。

## 两阶段模型路径

**复赛路径：官方基座 → 原生输入适配 → 官方任务头/允许的微调 → 七赛道评测。** 冻结、adapter、全量微调是待比较的策略，须先核对官方架构和规则。现有本地检查点初始化不能证明官方模型已经接通。

**决赛路径：自研编码器随机初始化 → 获准语料预训练 → 七赛道适配与评测。** 不将公开 EEG/时序教师、复赛基座或其蒸馏结果作为默认的决赛初始化来源。冻结公开教师仍然使用公开权重，不能借“学生从零初始化”绕过限制。纯随机初始化、掩码重建、EMA 自教师及对比学习优先作为待验证路线；所有数据与初始化仍按最终规则审计。多个从零训练的自建教师只有在正式规则允许且单教师已有验证收益时才加入。

多教师属于后续增益候选，不是七赛道覆盖的前提。任务已经由官方接口给出时直接选择对应头，不预先添加未知任务识别器。

## 准备是否足够

现有底座具备六种编码器、多种目标、微调、蒸馏及剪枝接口，25 项自动检查和 17 条合成集成路径通过。但真实数据目录当前只有说明文件；没有真实 EEG 导入、领域基线或七赛道结果。228.5 万参数候选只实例化计数，小模型的 GPU 测量不能代表该候选的真实输入、多教师或长记录成本。

所以：代码已能作为工程起点；尚不能证明 EEG 泛化、预训练收益、七赛道覆盖或正式提交可用。接下来补真实输入和匹配对照，比继续增加架构分支更有价值。

## 数据下载优先级

以下是独立诊断候选，不是公告所指的官方下游数据或 OpenNeuro 21 数据集清单。每个源先核对许可、版本和文件清单，原始文件与衍生数据分开。预检数据即使公开，也不会自动取得比赛训练使用许可。

| 优先级 | 数据或材料 | 计划下载范围 | 用途与限制 |
|---|---|---|---|
| P0 | [PhysioNet EEGMMIDB v1.0.0](https://physionet.org/content/eegmmidb/1.0.0/) | 先 3 名被试的 R04/R08/R12 EDF 与注释，再按预定义筛选扩到约 20 名；附通道说明、许可、事件说明 | 验证 64 通道、160 Hz EDF、运动想象标签和跨被试学习。R04/R08/R12 为左右手想象；T1/T2 含义必须结合 run 解析，不能混入双拳/双脚或运动执行 run |
| P0 | [Sleep-EDF Expanded v1.0.0](https://physionet.org/content/sleep-edfx/1.0.0/) | 先 3 名 sleep-cassette 被试各一对 PSG/hypnogram，再按需要扩到约 20 名，每人先取一夜；附评分说明 | 验证 100 Hz EEG、少通道、整夜切片与阶段标签。PSG 与 hypnogram 必须配对；阶段合并、未知/运动标签、醒期裁剪须预先定义。多夜同人不能分到不同集合 |
| P0 条件项 | SSVEP Benchmark 官方分发 | 先确认官方许可及是否支持逐被试下载，支持则取 3 名，再扩展；若只能整包分发，先登记大小，不默认下载整包 | 检验周期、频率、相位和观察窗。保存刺激频率/相位、标签及说明。当前尚未核验分发文件和下载量 |
| P1 | 官方 OpenNeuro 21 数据集清单及 BIDS 元数据 | 清单公布后，逐 accession/快照获取 dataset_description、participants、channels、events、JSON sidecar 与一个代表记录 | 验证多中心、异构通道、参考与事件读取；先元数据后信号，避免下载与赛事无关的全部 OpenNeuro |
| P1 | 疾病诊断代表数据 | 优先选择官方清单中的数据，先少量被试及诊断/纳排定义 | 若考虑 TUAB 等额外资源，先处理访问申请和许可，不将其视为可以立即下载的无条件公开文件 |
| P1 | 认知情绪、自然刺激解码代表数据 | 以官方清单中的一个小数据集分别做适配；同时获取刺激内容、时间戳和目标定义 | 通用“EEG 文件能读”不等于目标可构建；需区分分类、连续回归、检索或刺激重建 |
| P0 材料 | 官方规则、OmniEEG-Bench、官方基座配置/代码/许可 | 发布后保存确切版本、提交说明、示例输入输出；先查权重大小，再决定诊断下载 | 复赛首先用官方参考路径接通；决赛独立审计权重来源。当前尚无可核验的官方仓库/权重链接 |

上述两个 PhysioNet 数据页于 2026-10-10 实际访问成功（HTTP 200）；页面均注明 Open Data Commons Attribution License v1.0。此次只核对网页，未下载信号文件。使用时仍保存当时的许可文本、数据版本、选中文件和 SHA-256。

建议位置：`data/raw/precheck/<dataset>/<version>/` 存放不修改的原始文件；`data/processed/precheck/<protocol>/` 存放衍生 NPZ 和 manifest；`experiments/outputs/<run-id>/` 存放结果。正式比赛语料放入独立目录，台账注明“预检/复赛/决赛”、许可和初始化用途。下载时先核验路径及剩余磁盘。

### 七赛道覆盖的边界

| 赛道 | 当前最小验证内容 | 不足及下一步 |
|---|---|---|
| 信号可靠性 | 在真实 EEG 上加入明确标注的通道丢失、饱和、噪声与缺测，检查掩码和退化行为 | 人工扰动是鲁棒性诊断，不能替代官方可靠性标签和真实伪迹评测 |
| 疾病诊断 | 被试/就诊记录身份审计、诊断标签准入、窗口到被试预测聚合设计 | 等候实际疾病和标注；不能把 MI 分类头已能运行等同于疾病诊断已覆盖 |
| 睡眠分期 | PSG/标签对齐、30 秒 epoch、整夜顺序、少通道和类别不平衡 | 官方阶段映射和上下文访问约束待确认；当前 patch 级序列头不是现成的 30 秒分期协议 |
| 认知情绪 | 离散/连续标签、刺激/试次分组、分类或回归头 | 获得真实目标后验证，不把主观评分与任务条件混作同一种标签 |
| 运动想象 | EDF/事件、左右手想象、跨被试、少样本迁移 | 预检成绩只适用于所选 MI 协议 |
| 自然刺激解码 | EEG 与音频/视频/文本时间对齐，目标生成与评价接口设计 | 当前无完整刺激检索/重建头；已有回归接口只能覆盖目标允许的部分任务 |
| SSVEP | 频率/相位保真、窗长、滤波/重采样影响、周期性基线 | 短 patch 的幅值谱可能丢相位与频率分辨率；必须做真实数据对照 |

## 最小测试顺序与验收

各项执行前沿用 [赛前准备记录模板](赛前准备记录模板.md) 的阶段启动单。下面均为计划，没有新的完成勾选。

| 顺序 | 测试 | 建议范围 | 验收及失败处理 |
|---|---|---|---|
| 1 | 原始数据到 NPZ/manifest | MI、睡眠各 3 名；仅用于导入调试 | 检查真实通道、单位、事件/标签、记录边界、有限值和哈希；查看波形与频谱。失败先修导入，不进入比较 |
| 2 | 极小真实样本训练检查 | 约 16–32 个训练 trial/epoch；现有 compact 编码器 | 有效梯度、损失和标签对应；可过拟合只算学习链路检查。另设标签置乱/元数据捷径排查，不设通用准确率门槛 |
| 3 | 跨被试监督对照 | MI/睡眠各约 20 名，示例 16/2/2；实际人数与排除预先登记 | 先冻结身份、划分和预算，再切窗；先单种子调试，候选比较用预定义三个种子。不使用小验证集宣称可靠总体优越性 |
| 4 | 领域基线 | MI：CSP+LDA；睡眠：合理的小模型/特征基线；SSVEP：CCA/FBCCA | 选择与任务匹配的成熟实现，先检查已有依赖；与自研模型使用同一数据、协议、指标与调参预算 |
| 5 | 随机初始化预训练→迁移 | 一个掩码目标，比较 scratch、线性探测、全量/adapter | 对照含预训练数据访问和总成本；预训练不得接触本地保留测试被试。若无验证收益先保留监督基线，不增加目标 |
| 6 | 主候选真实尺寸资源 | 真实短窗、少通道长记录、64 通道长窗；先 batch=1，再逐步增大 | 测真实 forward/backward、EMA、优化器峰值与端到端延迟；多教师按实际配置另测。显存不足时缩 batch/窗长或启用已验证的轻量分支 |
| 7 | 真实扰动与迁移退化 | 丢通道、顺序变换、采样率变化、噪声、不同窗长 | 扰动记录物理量和语义影响；SSVEP 检查频率/相位，睡眠检查阶段边界。无官方在线要求时不把流式优化作为首要任务 |
| 8 | 官方协议与提交演练 | 官方文件发布后 | 固定 8:1:1、三种子和官方指标；干净环境加载、预测顺序/类型、七赛道聚合和初始化审计；首次提交前接通参考 baseline |

例示 16/2/2 只用于小规模预检，并非官方数据的完整划分。3 名被试导入检查不用于模拟 8:1:1 或证明泛化。三种子编号先用于本地开发记录；官方/B 榜的保密种子不能预先猜测。最终测试保留，不进入剪枝；排行榜反馈另行记账。

多教师实验排在这些检查之后：先单教师，再等权/固定权重，最后学习门控；复赛是否准入取决于规则。不能同时改编码器、目标和教师数量后将收益归因于其中一个模块。

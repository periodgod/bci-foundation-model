# 能力与代码对应表

这份表回答一个具体问题：**对外说的每一项能力，代码里到底在哪一行、有没有被实验验证过。**

分三档表述：`已实现且有实验` / `已实现未验证` / `未实现`。对外汇报时只能按实际档位说，
不要把第三档说成第一档。

| 能力 | 状态 | 代码位置 | 证据 |
|---|---|---|---|
| 任意通道数输入 | 已实现，有结构测试 | `data.py` 通道契约（电极 ID + 三维坐标 + `coord_valid` 三者强校验）；`model.py` 坐标经 `nn.Linear(3,d)` 与电极 ID 嵌入相加；BiasedAttention 用 key 掩码屏蔽无效通道 | `tests/test_montage.py`：64 导补 16 个无效通道后 logits 差异严格为 0 |
| 真实电极坐标 | 已实现，有几何测试 | `montage.py`：MNE `standard_1020` 模板查表，双极导联取中点；`realdata.py` ingest 时写入 `coords` / `coord_valid`，解析率 <90% 直接报错 | `tests/test_montage_coordinates.py`：EEGMMIDB 64 导 64/64 解析，C3–C4 = 0.133 m；旧数据实测 `coord_valid=0`、坐标全零，本轮已修 |
| 图条件注意力（电极距离偏置） | 已实现，**未验证** | `model.py` `GraphBlock` + `BiasedAttention`：成对距离经高斯基展开、线性映射为每头加性偏置，零初始化 | `tests/test_graph_bias.py`：零初始化偏置恒 0、填充不变、通道置换等变；**尚无性能对照结果** |
| 导联丢弃增广 | 已实现，**未验证** | `engine.py` `drop_channels()`，配置项 `training.channel_dropout` | 单测覆盖"至少留 1 通道、不越界改填充"；未做 A/B 对照 |
| 可变电极查询层（通道数压缩到固定槽位） | 已实现，**未验证** | `model.py` `latent` 分支：`self.queries` 作为可学习 query，对任意数量通道做 cross-attention | 无跨布局实验。T1 只做了通道屏蔽，没做 query 压缩后的性能 |
| 通道-时间掩码预训练 | 已实现，有实验 | `model.py` `mask_token` + `patchify`；`engine.py` `make_mask(..., mask_kind)` | 10 被试睡眠任务：掩码预训练 69.18 vs 从零 67.17（全量语料待重跑） |
| 缺失通道鲁棒性评测 | 已实现，**有结果，方向为负** | `scripts/eval_channel_dropout.py`（随机下采样）、`scripts/eval_montage_loso.py`（LOSO 协议下的固定布局 + 脑区移除 + 随机丢弃） | LOSO 基线 0.660；32 导 −0.079、19 导 −0.090、8 导 −0.131（10/10 折变差）、3 导 −0.140（10/10）。结构化与随机移除几乎等价，说明拓扑未被真正利用 |
| 冻结表征探测 | 已实现，有实验 | `engine.py` `tuning="frozen"` | 睡眠任务上冻结探测明显低于全量微调，增益主要来自微调而非冻结表征 |
| 通用轻量适配器 | 已实现（非域对齐） | `model.py` `self.adapter`，末层零初始化 | 用于残差微调，**不是**多图拓扑适配器 |
| 多图拓扑适配器（空间图 + 功能图 + 域对齐） | **未实现** | 仅有通用 adapter 与当前的单图距离偏置 | — |
| BSG 平衡符号图展开 | **已移除** | 历史提交 `35e4dea` | 不在当前训练管线，所有检查点均为 attention 系 |
| EEG-to-LLM 投影与指令微调 | **未实现** | 无 | — |
| 跨数据集 / 跨设备迁移 | **未实现** | 数据层已有 2a（22 导）/2b（3 导），但尚未接入统一预处理 | 需重参考 + 重采样 + 坐标对齐后才算真实跨设备 |

## 当前最重要的讨论顺序

1. 项目第一阶段目标：我们到底要服务哪些下游任务。
2. 数据账本：我们手上和计划收集的数据有哪些。
3. 预处理规范：什么能做，什么不能做。
4. 模型输入规范：通道、采样率、片段长度、patch。
5. 评估协议：如何证明不是数据泄漏或偶然高分。

# 联合预训练与共享基座规范

2026-10-11。原生 MI 与睡眠各自训练不能验证共享基座，因此增加一个有界联合实验。它验证同一预训练检查点能够合法接入两个任务；单种子、输入协议改变，不用于宣称跨任务性能优势。

## 输入与暴露

使用 foundation-direct-20261011 中已冻结的两个原生 study manifest：MI train270/validation135/test45；睡眠 train576/validation480/test1025。保持被试、会话、试次、验证与保留测试身份，不重新选择。

scipy.signal.resample_poly 将独立窗口转换到200Hz，使用line padding、保留伏特与原采集参考，属于离线输入变换。MI持续3.5秒变为64×700，睡眠30秒变为2×6000；不增加原数据的真实频率信息。原始事件采样率与起止点保存在parent字段，不能按200Hz误读原160/100Hz时间轴。

全局词表为已核验原生通道名称的并集。双极导联与单电极通道保持不同身份，不编造中点或坐标。词表、200Hz、单位和坐标契约写入三个manifest。各任务仍保持原标签；联合预训练文件移除所有target数组，unused_ssl_head只是未使用输出头的配置标记。

预训练仅拟合两项任务12名训练被试的窗口；6名验证被试只用于固定腐蚀验证损失选模型，2名原保留测试被试只做完整性审计。源训练/验证选择暴露沿初始化继续传播，不能通过少样本账本抹除上游接触。

## 批次与训练

batch_by_dataset=true将不同来源的窗口分别成批，再用已保存sampler随机状态打乱批次。避免一个MI窗口和一个睡眠窗口共同填充成64通道×6000样本。保持每个train窗口每epoch一次，除了对比目标明示的不足批次；本次目标为masked，不丢窗口。不同来源窗口数量不同，本实验按窗口计数加权损失，不声称任务等权。

同一个约4.91M参数fusion候选，200Hz、100样本patch，seed17，从零masked预训练3epochs、FP32、batch8。仅训练侧有重建/频谱/频带头。将其best.pt的encoder和训练归一化统计分别初始化到MI两类、睡眠五类的新任务头，每项full/linear各5epochs。冻结linear encoder逐参数检查不变。

## 验收

输入转换必须保持持续时间与数值有限、原始文件哈希一致、真实通道映射与目标语义。联合train中任何target出现都拒绝启动。新来源分组、波形重叠及源模型选择与保留测试冲突均拒绝。

预训练、两个full与两个linear的检查点、输入哈希、源初始化哈希、每人预测和训练显存留在joint-verified。完成后核验四个初始化记录引用同一个源checkpoint，线性encoder冻结且输出维度分别为2/5，任务契约一致。

模型效果单列，不与原生协议数值做因果比较：统一词表/重采样以及睡眠patch从1秒改成0.5秒均改变输入条件。三种子、数据预算、无联合预训练且同一200Hz输入的配对实验仍是进一步收益论证条件。它不会补齐尚无真实输入验证的五条赛道、几何注意力、整夜上下文和官方权重接口。

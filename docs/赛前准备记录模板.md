## 文献与复现卡

- 身份：标题、作者、年份、会议/期刊、DOI、arXiv ID及版本。
- 来源：官方论文/仓库URL、访问日期、代码提交、许可、文件路径与SHA-256。
- 阅读深度：元数据 / 摘要 / 全文 / 代码 / 本地执行，不能混写。
- 协议：任务、数据版本、划分、预处理、标签、指标、聚合单位、训练预算。
- 复现目标：具体表格/结果、源结果、前提、所需资源、允许误差依据。
- 优先级：与目标相关性、协议可比性、完整性、算力成本、许可；不按星数直接排序。
- 本地结果：运行ID、数值、协议偏差、验收状态；未运行时留空。

## 数据卡

- 数据集ID/版本、官方URL、许可/访问限制、用途与批准规则。
- 文件清单、SHA-256、原始格式、压缩与解压空间估算。
- 受试者/会话/运行/试次数量，真实标签映射与类别分布。
- 采样率、幅值单位、通道名称/位置、参考、电极类型、坏通道。
- 事件单位/时间基准、epoch边界、缺失/排除样本及原因。
- split manifest位置与哈希、衍生版本、预训练重叠审计状态。

## 实验卡

- 输入形状/单位、模型模块、参数量/可训练参数、目标函数。
- 随机种子、few-shot episode/support/query、优化器、学习率、调度、批大小、精度。

# 能力与代码对应表

这份表回答一个具体问题：**对外说的每一项能力，代码里到底在哪一行、有没有被实验验证过。**

分三档表述：`已实现且有实验` / `已实现未验证` / `未实现`。对外汇报时只能按实际档位说，
不要把第三档说成第一档。

| 能力 | 状态 | 代码位置 | 证据 |
|---|---|---|---|
| 任意通道数输入 | 已实现，有结构测试 | `data.py` 通道契约（电极 ID + 三维坐标 + `coord_valid` 三者强校验）；`model.py:195-196` 坐标经 `nn.Linear(3,d)` 与电极 ID 嵌入相加；`model.py:81` attention 用 `key_padding_mask` 屏蔽无效通道 | `tests/test_montage.py`：64 导补 16 个无效通道后 logits 差异严格为 0 |
| 可变电极查询层（通道数压缩到固定槽位） | 已实现，**未验证** | `model.py:207-215` `latent` 分支：`self.queries` 作为可学习 query，对任意数量通道做 cross-attention | 无跨布局实验。T1 只做了通道屏蔽，没做 query 压缩后的性能 |
| 通道-时间掩码预训练 | 已实现，有实验 | `model.py:188` `mask_token` + `patchify`；`engine.py:361` `make_mask(..., mask_kind)` | 睡眠任务：掩码预训练 69.18 vs 从零 67.17 |

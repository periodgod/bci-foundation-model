# 基础模型直接验证协议

2026-10-11。按用户最新要求，暂停新增普通模型基线，直接验收自研基础模型代码与设计。历史基线结果保留为证据，不作为本轮工作中心。

## 实际候选

主候选使用 fusion，D=256、5 层、4 个注意力头、FFN ratio=3、dropout=0.1，约 4.91M 参数。每通道 raw patch 投影、局部卷积、幅度频谱投影经拼接融合，叠加通道身份/可用坐标及时间位置，再执行时间与空间分解注意力。训练侧增加波形、频谱及频带重建；下游提供分类与其他已有任务头。

MI 输入 64×560，160 Hz，0.5s patch。睡眠输入 2×3000，100 Hz，1s patch；保留真实双极导联。两者目前分别训练，不能把不同来源的同号 channel ID 当成同一电极，也不能宣称已实现一个跨采样率、跨词表的共享检查点。

## 开始运行前冻结

实际启动单为 experiments/outputs/foundation-direct-20261011 下各目录的 launch.json，记录父账本与抽样账本哈希。数据扩展到每类 10 名被试，训练/验证/保留测试为 6:3:1，保持原 S003/SC402 保留被试；这是开发协议，不是官方 8:1:1。

MI 全训练与验证窗口进入实验。睡眠按标签无关固定随机抽样，训练最多 96 epochs/人、验证最多 160 epochs/人，选择种子 20261011；不按阶段比例或模型结果挑选。测试记录留在账本，仅完整性审计，禁止生成测试预测。

三训练种子为 17、29、43。全量监督、线性及 adapter 各 5 epochs；掩码预训练 3 epochs，联合 mask=0.5、波形权重1/频谱0.1/频带0.01。EMA 和双教师工程路径仅 seed17，不用于宣称多种子收益。所有训练 FP32、batch8，单运行上限1800秒。标签权重仅由该运行训练集计算。

## 验收分层

| 验收 | 方法 | 通过后允许说什么 |
|---|---|---|
| 架构链路 | 六种架构在真实 EEG 上前向、反向及 AdamW 更新；关键支路梯度有限且非零 | 当前真实输入可训练 |
| 遮盖隔离 | 任意改变被 mask 的 raw 样本，编码 tokens 严格不变 | 这些测试输入中未发现目标偷看 |
| 通道身份 | 信号、身份、坐标、有效性同步重排，分类输出在数值容差内一致 | 数组顺序不替代物理身份 |
| 来源链 | 预训练、教师及其上游训练组/波形与当前 held-out 冲突立即拒绝；源验证选择不得接触当前测试组 | 当前记录下的来源污染被拦截 |
| 适配 | full/linear/adapter 从相同预训练源开始；冻结参数逐项对比 | 冻结策略按设计执行 |
| 教师 | 本地从零训练来源，两个独立投影；固定或学习权重；检查教师参数和梯度 | 双教师训练链路可执行 |
| 学习收益 | 主体平均 BA、macro-F1、混淆及各阶段召回，三种子配对 | 有限开发样本上的探索性结果 |
| 部署 | 保存源码在 Python -I 新进程加载推理权重，CPU 输出逐项一致 | 本机离线加载链路成立 |

所有 SSL 检查点的随机/未监督任务头分类分数仅为诊断，不能当自监督迁移收益。迁移收益只比较经过下游训练的 head。fusion 对 factorized 同时取消卷积/频谱融合，是组合模块消融，不是纯频谱单因素因果证据；参数量也不完全相等。预训练+微调多出预训练预算，须单列成本。

## 设计中尚未成立的部分

当前坐标层是线性坐标编码，不含距离或几何注意力偏置。本批公开 EDF 没有经核验的坐标，坐标支路不被本批数据训练。hierarchical 聚合发生于单窗口内部，不等于整夜上下文模型。causal 模型检查不证明 MI 零相位预处理可在线。

0.5s 幅度 FFT 分辨率为2 Hz，不能凭其覆盖0.2 Hz间隔 SSVEP，且幅度谱不保留相位；raw 投影保留样本，但仍需相位任务的实际验证。多教师门控由匹配损失学习，熵约束不保证质量判断；本轮教师为同来源本地模型，不代表外部 EEG/通用时序教师已经接通。

官方基座、21 个 OpenNeuro 数据集清单、完整评分、任务输出及算力配置仍是外部依赖。当前两个任务、局部窗口训练，不足以证明七赛道统一基础模型设计正确。结论应逐模块标为通过、无收益、待验证，不能把工程通过等同比赛方案成立。

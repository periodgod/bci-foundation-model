# 脑电大模型完整实验方案

本文档规定项目从数据准备到最终报告的完整实验顺序。正式训练前必须先完成本文档中的数据账本、baseline、sanity check 和输出格式约定。

## 0. 当前项目定位

项目第一阶段不做泛 EEG 通用大模型，而做：

```text
基于 PhysioNet Motor Movement/Imagery 的 5M 级 MI+ME 领域基础模型，
用于自采 8 分类 MI+ME 任务的极少样本快速微调。
```

核心问题：

```text
PhysioNet 上预训练得到的 MI/ME 表征，
是否能提升我们自采 8 分类 MI+ME 在极少样本条件下的表现？
```

## 1. 总体实验链路

必须按以下顺序执行：

```text
S0 项目与环境冻结
S1 PhysioNet 数据下载与账本
S2 数据读取与质控
S3 预处理与切窗
S4 传统 baseline
S5 1M-2M sanity model
S6 5M 主模型预训练
S7 PhysioNet 内部验证
S8 自采 8 分类 MI+ME 数据质控
S9 极少样本微调
S10 消融实验
S11 结果汇总与报告
```

禁止跳过 S4 和 S5 直接训练 5M 模型。

## 2. 目录规范

```text
projects/脑电大模型/
  configs/          模型、训练、评估配置
  data/             数据账本和轻量索引，不放大文件
  docs/             设计与实验文档
  experiments/      每次实验的配置快照和日志索引
  figures/          论文/报告用图片
  reports/          阶段报告、结题材料、复现实验说明
  results/          CSV/JSON 指标结果
  scripts/          可执行脚本
  src/              模型与数据处理代码
```

## 3. 数据与切分

### 3.1 PhysioNet 数据角色

PhysioNet 用于：

- 自监督预训练。
- ME/MI 状态 probe。
- 动作类别 probe。
- 跨被试验证。

PhysioNet 不用于最终宣传“8 分类成功”，因为最终目标是我们自采的 8 分类 MI+ME。

### 3.2 自采 MI+ME 数据角色

自采数据用于：

- 最终极少样本微调。
- 8 分类评估。
- 与传统 baseline 对比。

### 3.3 数据切分原则

PhysioNet：

```text
train_subjects: 约 70%
val_subjects: 约 15%
test_subjects: 约 15%
```

自采数据：

```text
within_subject: 同被试训练/测试，报告少样本适配能力
session_holdout: 留出 session，检查跨 session 稳定性
subject_holdout: 如果被试足够，做跨被试验证
```

严禁：

- trial 级随机混合后宣称跨被试泛化。
- 使用测试被试参与预训练调参。
- 用重叠窗口同时落入 train 和 test。

## 4. 输出格式总表

所有实验必须至少输出：

| 文件 | 格式 | 说明 |
| --- | --- | --- |
| `config.yaml` | YAML | 本次实验配置快照 |
| `metrics.json` | JSON | 单次实验主要指标 |
| `metrics.csv` | CSV | 多轮/多被试结果长表 |
| `splits.json` | JSON | train/val/test subject/session 列表 |
| `run_log.txt` | TXT | 运行日志 |
| `environment.txt` | TXT | Python、PyTorch、CUDA、包版本 |
| `figures/*.png` | PNG | 快速查看图片 |
| `figures/*.pdf` | PDF | 报告/论文矢量或高清图 |

建议每个实验目录：

```text
experiments/YYYYMMDD_HHMMSS_experiment_name/
  config.yaml
  splits.json
  run_log.txt
  environment.txt
  checkpoints/
  results/
  figures/
```

## 7. S2 数据读取与质控

目标：

先看原始数据质量，不盲目滤波。

每个 subject 至少抽样检查：

- 原始波形。
- PSD。
- 通道方差。
- flat channel。
- 极端幅值片段。

输出：

```text
results/quality/physionet_channel_quality.csv
results/quality/physionet_bad_segments.csv
figures/quality/*.png
```

`physionet_channel_quality.csv` 字段：

```csv
subject,run,channel,variance,flat_ratio,peak_to_peak,psd_8_30,quality_flag
```

需要画图：

| 图 | 文件 |
| --- | --- |
| 原始 EEG 波形示例 | `figures/quality/raw_trace_examples.png` |
| 滤波前 PSD | `figures/quality/raw_psd_examples.png` |
| 通道方差热图 | `figures/quality/channel_variance_heatmap.png` |
| 坏道数量分布 | `figures/quality/bad_channel_count_hist.png` |

通过条件：

- 能列出坏道和异常片段规则。
- 不做盲目 ICA。

## 8. S3 预处理与切窗

目标：

生成统一训练样本索引。

默认预处理：

```text
sampling_rate: 160Hz
bandpass: 0.5-45Hz
MI analysis band: 8-30Hz
notch: 按需要，记录是否使用
reference: average reference
window: 4s
stride: 4s for evaluation
patch: 0.5s
```

训练阶段可允许 stride 小于 4s，但评估必须使用非重叠窗口，或单独报告 overlap。

输出：

```text
data/physionet_windows.csv
results/preprocess/preprocess_summary.json
```

`physionet_windows.csv` 字段：

```csv
window_id,dataset,subject,run,start_sec,end_sec,event_name,state_label,body_label,n_channels,sampling_rate,split
```

需要画图：

| 图 | 文件 |
| --- | --- |
| 不同类别窗口数量 | `figures/preprocess/window_label_counts.png` |
| train/val/test 被试数 | `figures/preprocess/split_subject_counts.png` |
| mu/beta bandpower 类别分布 | `figures/preprocess/bandpower_by_label.png` |

通过条件：

- 每个窗口能追溯回原始文件、subject、run、事件。
- train/val/test 按 subject 或 session 切分。

## 9. S4 传统 baseline

目标：

先知道传统方法能做到什么水平。

必须跑：

- FBCSP-LDA。
- Riemannian tangent space。
- EEGNet。
- MiniRocket，可选。

任务：

```text
state_2class: ME vs MI
body_4class: left_hand / right_hand / both_hands / feet
joint_8class: 如果标签可构造
```

输出：

```text
results/baselines/baseline_metrics.csv
results/baselines/baseline_subject_metrics.csv
```

`baseline_metrics.csv` 字段：

```csv
experiment,model,dataset,task,split,accuracy,balanced_accuracy,f1_macro,kappa,seed
```

需要画图：

| 图 | 文件 |
| --- | --- |
| baseline 总体柱状图 | `figures/baselines/baseline_overall_bar.png` |
| 每被试准确率箱线图 | `figures/baselines/baseline_subject_boxplot.png` |
| 混淆矩阵 | `figures/baselines/baseline_confusion_matrix.png` |

通过条件：

- 至少有一个传统 baseline 明显高于随机。
- 如果全部接近随机，优先回查事件对齐、窗口、标签和预处理。

## 10. S5 1M-2M Sanity Model

目标：

验证预训练任务和模型代码是否真的能学。

模型：

```text
d_model: 128 或 160
depth: 4
heads: 4
参数: 1M-2M
```

输出：

```text
results/sanity/pretrain_loss.csv
results/sanity/probe_metrics.csv
figures/sanity/pretrain_loss_curve.png
```

必须检查：

- 单 batch overfit。
- reconstruction loss 是否下降。
- mask 后重建是否比均值预测好。
- probe 是否高于随机。

通过条件：

- 训练 loss 和验证 loss 都合理下降。
- 没有 NaN。
- 线性 probe 至少在 state_2class 上高于随机。

## 12. S7 PhysioNet 内部验证

目标：

确认预训练 encoder 在 PhysioNet 上学到了 MI/ME 相关表征。

评估方式：

1. frozen linear probe。
2. full fine-tuning。
3. 少样本 fine-tuning。

任务：

```text
state_2class
body_4class
joint task if label mapping is valid
```

输出：

```text
results/probe/physionet_probe_metrics.csv
results/probe/physionet_subject_metrics.csv
```

需要画图：

| 图 | 文件 |
| --- | --- |
| probe vs baseline | `figures/probe/probe_vs_baseline.png` |
| 每被试 probe 表现 | `figures/probe/subject_probe_boxplot.png` |
| 混淆矩阵 | `figures/probe/probe_confusion_matrix.png` |
| t-SNE/UMAP 表征可视化 | `figures/probe/embedding_umap.png` |

通过条件：

- frozen probe 不能明显低于传统 baseline。
- full fine-tune 应优于或接近 EEGNet。
- 如果 probe 随机，说明预训练目标没有学到任务相关表征。


需要画图：

| 事件时间线 | `figures/local/event_timeline.png` |

## 14. S9 极少样本微调

目标：

验证基础模型是否提升我们自采 8 分类 MI+ME。

few-shot 设置：

```text
1, 3, 5, 10 trials/class
```

微调策略：

1. frozen encoder + linear head。
2. LoRA / adapter。
3. full fine-tuning，仅作为上限。

分类头：

```text
state head: 2-class
body head: 4-class
joint head: 8-class
```

输出：

```text
results/fewshot/local_fewshot_metrics.csv
results/fewshot/local_fewshot_subject_metrics.csv
```

`local_fewshot_metrics.csv` 字段：

```csv
experiment,pretrain,finetune_method,task,shots_per_class,subject,session,accuracy,balanced_accuracy,f1_macro,kappa,seed
```

需要画图：

| 图 | 文件 |
| --- | --- |
| shots vs accuracy | `figures/fewshot/shots_accuracy_curve.png` |
| 预训练 vs 从零训练 | `figures/fewshot/pretrain_vs_scratch.png` |
| 层级头 vs flat 8-class | `figures/fewshot/hierarchical_vs_flat.png` |
| 每被试少样本提升 | `figures/fewshot/subject_improvement.png` |
| 8 分类混淆矩阵 | `figures/fewshot/local_8class_confusion_matrix.png` |

通过条件：

- 至少在 5-shot 或 10-shot 下超过传统 baseline。
- state_2class 和 body_4class 的结果能解释 8 分类结果。
- 多 seed 结果稳定，不只报告最好一次。

## 15. S10 消融实验

目标：

证明改造点是否有效。

必须做：

| 消融 | 对比 |
| --- | --- |
| 频带特征 | raw only vs raw + mu/beta bandpower |
| 分解注意力 | full attention vs temporal+spatial factorized |
| mask 策略 | random mask vs motor-region-biased mask |
| 预训练 | scratch vs PhysioNet pretrained |
| 分类方式 | flat 8-class vs hierarchical heads |
| 模型规模 | 1M-2M vs 5M |

输出：

```text
results/ablations/ablation_metrics.csv
figures/ablations/ablation_summary.png
```

通过条件：

- 至少能说明哪些模块有用，哪些模块没用。
- 如果某个复杂模块无收益，后续应删掉。

## 17. 成功标准

最低成功标准：

```text
完成完整 pipeline；
传统 baseline、1M sanity、5M 主模型均可复现；
明确解释随机结果的原因。
```

有效模型标准：

```text
5M 预训练模型在自采 MI+ME few-shot 下，
至少一个核心设置超过 FBCSP/Riemannian/EEGNet baseline。
```

强成功标准：

```text
5M 模型在 5-shot 或 10-shot 下，
8 分类 balanced accuracy 稳定超过传统 baseline，
且 state/body 层级结果具有可解释性。
```

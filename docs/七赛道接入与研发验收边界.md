架构链路检查验证可用输入上的数学/工程性质；数据集和比赛任务的有效性必须分别验收。七赛道原始 BA/F1/MSE 不可直接等权平均冒充官方综合分数。正式指标发布后由各赛道指标模块输出统一评分协议认可的分数。

## 开赛接入顺序

1. 保存官方规则、数据版本和来源；确认复赛公开基座与决赛从零来源要求。公开教师即使冻结，也属于公开权重使用。
2. 按记录亲缘确定 split，处理单位、真实通道词表、采样率/参考、事件与标签。跨来源通道号和同名被试不混用。
3. 先使用已通过本机验收的自研候选检查输入与目标链路，再实现实际需要的新头。无需自动新增一轮普通模型基线。
4. 在训练/验证上做有限模块实验，记录各来源训练与验证选择暴露。不同采样率/词表的预训练权重现在会被拒绝，接入前必须实现并验收真实输入统一方案。
5. 冻结候选、任务头、预处理及官方容器，最终测试访问留账本。推理只交付学生与必要的任务组件。

## 目前可以完成与不能提前签收的事项

可以在公开数据上完成架构梯度/遮盖检查、从零预训练、适配/蒸馏链路、显存实测、来源审计、离线推理一致性及结果记录。真实两个任务的结论只适用于这些任务和预算。

# OmniEEG 初赛主赛道 PPT 设计规格

## 目标

制作一份用于初赛专家评审、可独立阅读的 16:9 研究方案演示文稿。评委需要快速判断团队是否准确理解赛制、是否从文献和基线推导出研究问题、方法能否执行，以及实验能否公平验证主张。它服务于科研审查，不是宣传路演；页面应先给结论，再给能支撑结论的图、比较和条件。评审者应能把每页内容映射到评分细项。

## 统一内容

三种设计方向使用完全相同的方案内容，只改变版式、字体、色彩和图表表达。项目选择主赛道，自动覆盖信号可靠性、疾病诊断、睡眠分期、认知与情绪识别、自然刺激解码、运动想象和 SSVEP 七类任务；不把任何一种任务作为整体方案的重点。官方披露输入为 4–128 通道、1–30 秒并统一重采样至 200 Hz，覆盖 14 个下游数据集。封面仅写赛事名称、方案标题、主赛道；队伍和成员信息由用户后续补充，不出现“待填写”等提示语。

研究主张是检验从随机初始化开始训练的共享 EEG 表征能否迁移到七类任务，并按各赛道积分累计评价总体能力。相关工作需比较脑电基础模型的预训练目标与时空建模，以及七个任务领域的必要强基线；论文分数不可跨数据、划分和指标直接排序。研究见解应落到可检验决策：共享通道编码与分层时间编码支持通道数、窗口长度变化；任务输出头保持任务特性；是否保留频带或拓扑先验通过消融验证。

方法图需从输入到输出完整呈现：官方 21 个预训练语料及许可/被试核查、统一 200 Hz 输入、可变通道与可变时长编码、随机初始化掩码预训练、14 个下游数据适配、七类任务评测。不得宣称该架构已完成 OmniEEG 实测。复赛仅使用允许公开下载的权重做微调、线性探测或适配器实验；决赛在官方语料上从零训练，禁止加载任何预训练权重。方法参数未定时写明选择逻辑，不编造最优值。

实验页覆盖官方被试隔离 8:1:1、三个指定种子、验证集平衡准确率选模、测试集最终评价；以同架构随机初始化监督模型隔离预训练收益，并比较冻结探测、参数高效适配、全量微调和任务专用基线。消融只改变一个关键因素，分别检验通道聚合、时间建模、预训练目标和下游更新方式。判读规则预先定义稳定提升、局部提升、无提升及高波动时如何限定结论。现有项目的小规模自有数据实验与官方比赛数据不同，方向展示中不把它们冒充赛道结果；结果页写明暂无 OmniEEG 官方评测结果。

算力页说明使用组委会复赛/决赛官方共享 GPU 资源池，按统一调度使用，不申请个人或队伍独立配额。列出卡型/显存、卡数、单次时长、运行次数、用途和存储等要求；未知配置按官方资源池规格公布及首轮短测确认。预计运行次数标注预算口径和未纳入的消融/重跑，不用本机开发硬件替代官方算力。

## 视觉与文案约束

画布为 1920×1080。三方向均使用官方赛事标志资产与相同内容，正文不低于 24 CSS px、注释不低于 20 CSS px，保证投影可读。优先使用任务规格矩阵、方法流程、对照表和定量图表；不使用无信息量的照片、空白卡片、装饰英文、占位提示、虚构结果、渐变光球或社交媒体式装饰。技术缩写仅在学科语境确有必要时保留。视觉应有清晰主次和数据对比，不通过堆字填满页面。

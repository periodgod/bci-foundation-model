# 跨领域时序参考与架构预案

日期：2026-10-10。范围：赛前技术预案，覆盖通用时序、视觉表征、多教师蒸馏与 EEG。未写模型代码、未训练、未安装或下载模型权重。

## 1. 总体设计

不把候选限制在 EEG 论文。首先学习通用时序的 patch、跨变量交互、多尺度表示、状态空间、因果序列建模，再借鉴跨模态融合蒸馏。各方向的论文先提供方法假设，EEG 的实际迁移收益需独立验证。

预设架构按约束选择，不把所有能力叠到一个模型。共享设计层次为：

```text
数据/事件/任务契约
  -> 单位、通道、时间、有效 mask
  -> patch 或局部卷积 tokenizer
  -> 时间编码 + 必要的物理空间编码
  -> 时间主干 + 必要的跨通道交互
  -> 任务要求的 pooling / 序列聚合
  -> 独立任务头或适配器

训练侧可选：重建、对比、EMA 潜在预测、外部教师蒸馏
部署侧保留：选定编码器、必要的状态/适配器、任务头
```

教师选择、预训练目标与主干选择分开：同一个小型学生可比较自监督或蒸馏，同一种蒸馏也可比较不同学生主干。首轮只选一个可端到端验证的方案，其余是文档预案，不预先实现多套配置或兼容路径。

## 2. 跨领域论文地图

本轮已用 arXiv 元数据核对标题、编号与摘要。除 MTDP 方法与实验设置外，下面新增资料本轮主要读到摘要，没有完整审计论文、代码、许可证或权重。本表不是“最新最优模型”排名。近期预印本不能据此视作已充分验证。

### 2.1 优先借用的基础方法

| 优先级 | 论文 | 核心结构/目标 | 可借到哪里 | EEG 适配边界 |
|---|---|---|---|---|
| P0 | [PatchTST](https://arxiv.org/abs/2211.14730v2)，2022/2023 | 每变量切 patch，共享 channel-independent Transformer；支持掩码表征学习 | M05/06 的 tokenizer 与共享时间编码器 | 原始独立通道缺少跨电极交互；必要时只增加一个空间模块，并单独消融 |
| P0 | [iTransformer](https://arxiv.org/abs/2310.06625v4)，2023/2024 | 将变量作为 token，attention 建模变量相关，FFN 处理每变量时间信息 | M06 的空间/变量交互对照 | 整段变量 token 可能丢失事件级分辨率；电极坐标与参考需另处理 |
| P0 | [TS2Vec](https://arxiv.org/abs/2106.10466v4)，2021/2022 | 上下文视图的层次对比；时间点表征可聚合为子序列表示 | M07 的低复杂度无标签表征学习 | 正负样本和裁剪不能破坏事件标签或引入被试身份捷径 |
| P0 | [MOMENT](https://arxiv.org/abs/2402.03885v3)，2024 | 多来源通用时序表征与有限监督下游适配 | M03/06/07/09 的通用表征参考、候选教师 | 模型支持通用分析不等于原权重适合 EEG；先冻结探测与输入审计 |
| P1 | [TimesNet](https://arxiv.org/abs/2210.02186v3)，2022/2023 | 多周期将一维序列组织为二维，卷积分别刻画周期内/周期间变化 | M06 周期结构分支，SSVEP/节律候选 | 强非平稳或瞬态任务不一定适合；二维变换不能混淆时间轴与电极轴 |
| P1 | [TimeMixer](https://arxiv.org/abs/2405.14616v1)，2024 | 多尺度分解与 MLP 混合，细/粗尺度信息交换 | M06 的轻量多尺度时间主干 | EEG 不是简单趋势加季节项；下采样需保留任务频带，不照搬预测头 |
| P1 | [Tiny Time Mixers](https://arxiv.org/abs/2401.03955v8)，2024 起 | 轻量 patch/尺度混合，多分辨率与变量相关适配 | M06/08 的低资源设计参考 | 固定 token/channel mixing 的尺寸约束需检查，不能假定任意 montage 可用 |
| P1 | [TF-C](https://arxiv.org/abs/2206.08496v3)，2022 | 时间与频率表示的对比一致性 | M07 的时频表征目标，非波形重建对照 | 频率增强可能改变 SSVEP 类别，相位/瞬态信息不能一律作为不变因素 |
| P1 | [TS-TCC](https://arxiv.org/abs/2106.14112v1)，2021 | 弱/强增强视图，时间与上下文对比 | M07 的对比预测设计 | EEG 增强必须任务合法，不能原样继承所有时间变形 |
| P1 | [S4](https://arxiv.org/abs/2111.00396v3)，2021/2022 | 结构化状态空间，建模长依赖 | M06 长记录时间聚合器 | 实现依赖、mask、状态边界和性能需审计，不预先安装 |
| P1 | [Mamba](https://arxiv.org/abs/2312.00752v2)，2023 | 输入相关选择性状态空间，序列长度线性扩展 | M06/11 长序列或在线候选 | 论文复杂度不等于本机实际加速；因果性取决于完整管线 |

### 2.2 通用基础模型、近期创新与跨模态教师

| 论文 | 创新 / 适用角色 | 本项目应如何使用 |
|---|---|---|
| [Chronos](https://arxiv.org/abs/2403.07815v3)，2024 | 缩放量化序列值，用语言模型式 token 预测 | 时间模式教师候选；主要证据是预测，不直接宣称 EEG 分类通用性 |
| [TimesFM](https://arxiv.org/abs/2310.10688v4)，2023/2024 | patch decoder-only 预测基础模型，处理不同历史/预测长度 | 学习 patch 与多时长预训练；用隐藏特征前核实接口，不把预测值作为天然类别 |
| [Moirai](https://arxiv.org/abs/2402.02592v2)，2024 | 多频率、可变变量、跨分布的统一预测 Transformer | M03/05 异构采样与变量组织参考；“frequency”有采样频率含义，不能混同 EEG 频带 |
| [Moirai-MoE](https://arxiv.org/abs/2410.10469v1)，2024 | 自动 token 级稀疏专家，替代人工粗粒度频率专门化 | 借鉴软专家分工，不假定专家必对应七个赛道；首轮不做 MoE |
| [Timer-XL](https://arxiv.org/abs/2410.04803v4)，2024 | 因果多变量 next-token，时间/变量依赖建模 | 长上下文与严格时序接口参考；能预测不等于能分类 |
| [Chronos-2](https://arxiv.org/abs/2510.15821v1)，2025-10-17 | group attention 在相关序列/变量/协变量间共享上下文 | 多通道时序教师与变量混合候选；群组不能跨隔离被试或借测试标签信息 |
| [TiRex-2](https://arxiv.org/abs/2607.01204v1)，2026-07-01 | xLSTM 记忆、多变量混合、流式每 patch 成本不随历史增长 | 在线状态与跨变量建模候选；原论文针对预测，未来已知协变量不能替换成未来 EEG |
| [DINOv3](https://arxiv.org/abs/2508.10104v1)，2025 | 视觉自监督密集特征、Gram anchoring | 跨模态结构教师，输入可设计为波形图或谱图；必须验证转换没有破坏物理信息 |
| [AM-RADIO](https://arxiv.org/abs/2312.06709v5)，2023/2024 | 将不同目标的视觉教师压入一个共享学生，兼顾多类下游 | “共同基础特征 + 下游不同任务”直接借鉴；视觉结果只是研究动机 |
| [EEG MTDP](https://arxiv.org/abs/2603.04478v1)，2026 | DINOv3 与 Chronos-Bolt 门控融合，分两阶段蒸馏 EEG 学生 | 已有跨模态 EEG 先例；Chronos 原版、Bolt、Chronos-2 是不同模型，输入和权重不可混用 |

Moirai 此处是统一时序模型 `2402.02592`，不是同名的分布式推理设备放置论文。各模型版本、许可证、可访问权重与本地依赖仍需进一步核验。

## 3. 三类“教师”必须分开

| 类型 | 来源与作用 | 权重和知识约束 | 首轮用途 |
|---|---|---|---|
| EMA 自教师 | 当前学生的指数移动平均，稳定潜在目标 | 不依赖外部预训练知识，但仍要确认比赛训练协议 | JEPA 候选；不是外部多教师融合 |
| 外部通用教师 | 预训练时序、EEG、视觉模型，提供不同先验 | 外部知识进入学生，必须获准并记录来源/语料/版本 | 多教师候选；先独立验证有效性 |
| 专项任务教师 | 在允许训练数据上适配的 MI/睡眠等模型 | 标签空间与适用域明确，不能用无关任务输出教学生 | 同任务输出蒸馏，或共享特征蒸馏 |

先挑两个教师检验互补性：例如一个合法 EEG 教师加一个 MOMENT/Chronos 系列时序教师。视觉教师另作候选，不同时上三个。每个教师使用独立输入视图和特征投影，先比较独立特征损失；未经对齐不平均特征，更不能平均不同任务类别概率。

教师需要的输入不是学生推理必须增加的模态。视觉教师可看同一 EEG 的派生图像，学生仍看 EEG。若教师使用额外 ECG/EMG、临床描述或密集电极，必须有训练时合法配对，明确为特权信息，不能从推理缺失内容伪造教师输入。

## 4. 八种架构预案

这些预案按主导约束触发，可共享组件或组合约束，不表示必须训练八个模型。实际选定方案保持一个清晰运行入口，放弃的预案不留软件兼容分支。

| 预案 / 触发场景 | 预设架构 | 训练/适配策略 | 参考与关键验收 |
|---|---|---|---|
| A0：只允许规定语料从零训练，资源有限 | per-channel patch -> 共享小时间编码器 -> 坐标感知空间交互 -> masked pooling -> 独立任务头 | 先监督 scratch；再原波形 MAE。结构化 mask、频谱/EMA 目标逐项替换 | PatchTST + CBraMod/REVE 思路；前反向、mask、跨人迁移、实测显存 |
| A1：允许公开权重，标签少 | 保持官方 tokenizer/主干输入，新增线性头或小适配器 | 冻结探测 -> 部分解冻 -> 全量/LoRA 同预算比较 | EEGPT/REVE/MOMENT 候选；精确加载、输入与标签对应、少样本收益 |
| A2：允许外部教师，要求低成本部署 | 一个小型 EEG 学生 + 训练时双教师独立投影；任务 ID 选择任务头 | 单教师 -> 双教师等权 -> 固定加权；有效后才动态门控 | MTDP/AM-RADIO/MMKD；超过最佳单教师、无关键任务负迁移、部署无教师依赖 |
| A3：通道数/设备/电极布局变化大 | 坐标感知 per-channel patch -> learned-query C->Q 空间统一 -> 时间编码器 -> 任务头 | 合法缺道增强、不同布局验证；原通道重建需坐标条件 decoder | LUNA/Moirai 的异构组织；坐标/导联正确、重排与缺道契约、C->Q 解码 |
| A4：长记录、离线整段分析 | 局部短窗编码器 -> epoch/窗口表示 -> 长程时间聚合器 -> 序列或记录头 | 先窗口编码 + 简单时间卷积/注意力；长程瓶颈明确再 S4/Mamba | 分层时序、S4/Mamba；记录/被试级计分，长程上下文收益与资源 |
| A5：严格在线、低时延 | 因果预处理 -> 因果局部卷积/patch -> 因果状态主干 -> 增量任务头 | 初版因果 TCN/GRU 先验证；有收益/内核证据再选择因果 SSM/xLSTM | Timer-XL/TiRex-2 的因果/状态思想；无未来样本、状态 reset、流式与批处理等价 |
| A6：相位、瞬态或精确事件对齐敏感 | 保留原波形局部分支 + 相位/谐波可用的频谱分支 -> 有时间分辨率的编码器 -> 对齐输出头 | 波形、事件级或联合目标；band-power-only 只作对照 | TimesNet/TF-C/CBraMod 参考；SSVEP 谐波/相位、ERP 瞬态、延迟与对齐验证 |
| A7：真实任务未知、多用途部署 | 共享编码器 -> 任务适用性/拒识模块 -> 可兼容任务头；必要时软专家 | 首先判断是否有上下文元数据；确实未知才训练适用性模型；多标签与未知任务单独评估 | Taskonomy/Moirai-MoE 的关系/分工思想；不能强制七选一，门控不依赖数据集身份 |

A0 与 A3/A6 可组合，A2 也可蒸馏成 A4 的局部编码器。A5 的因果约束覆盖全部模块，不能接双向 encoder 或零相位滤波。A1 若换掉输入/主干语义，就不再是原 checkpoint 的直接适配。

资源极低或无标签语料不足时，EEGNet/紧凑时序卷积和合理传统方法仍是必须对照。它们是科学基线或独立可选方案，不是为旧实现保留兼容层。不能为了宣称“基础大模型”牺牲可用的端到端流程。

### 4.1 默认准备 A0，条件允许时检验 A1/A2

通用模块在文档中先定义为 `[B,C,P,D]`，物理通道与时间有效性始终随特征传递。时间编码可以借用通用时序思想，空间模块解决 EEG 特有的导联与坐标。原 MI/ME 的 mu/beta 先验放在任务层，不强制所有任务使用。

可讨论的小模型范围为 1M–5M，候选宽度 128/192、patch 时长 0.25/0.5 秒，层数由资源实测决定。这些是资源剖析候选，不是已证明可装入 8 GB 的最终规格。官方权重输入必须采用其原规格；任务最高有效频率和最低事件分辨率决定采样率及 patch，不能把统一参数强加到所有场景。

### 4.2 决策顺序

1. 先核实赛规：从零训练、公开权重、外部教师知识分别是否允许。
2. 判断任务 ID 是否已知、标签属于窗口/epoch/记录/被试、是否需要严格在线。
3. 审查真实通道、坐标、参考、采样率、记录时长和标签数量。
4. 从 A0/A1/A2 选择训练主线；必要时增加 A3/A4/A5/A6 的结构约束，A7 只在确实需要时启用。
5. 完成监督/自监督或教师单项基线，再替换一个模块。未知规则影响的分支只准备文档，先做独立的来源和接口核验。

## 5. 哪些模块可以学、哪些不能直接照搬

| 模块 | 跨领域可借内容 | 必须重新设计的部分 | 第一轮控制变量 |
|---|---|---|---|
| M05/06 tokenizer | PatchTST 分片；TimeMixer 多尺度；Chronos 量化 | EEG 单位、幅度、相位、事件与电极；量化误差可能损害弱信号 | 不同时改变采样、patch、频谱分支与主干 |
| M06 变量交互 | iTransformer 变量 token；Chronos-2 group attention | 电极几何、导联参考与不同被试隔离 | 相同时间主干，独立比较空间交互 |
| M06 时间主干 | attention、MLP mixer、SSM、xLSTM | mask、事件精度、因果/离线语义和本机内核 | 相同输入/任务头/目标，记录参数与吞吐 |
| M07 预训练目标 | TS2Vec/TS-TCC 对比、TF-C、MOMENT 表征、多教师 | EEG 合法增强、目标泄漏、语料重叠、监督权限 | 先选择一种目标；频带丢相位要任务验证 |
| M09 任务迁移 | 线性 probe、适配器、共享表征多头 | 分类/回归/分割/对齐的标签和损失不相同 | 同 split、支持集和标签预算 |
| M11 推理 | 流式状态、token 合并、学生压缩部署 | 无未来信息、记录边界、输出顺序与官方计分 | 先确认精度，再实测部署收益 |

单个变量的天气/零售预测先验未必保留 EEG 空间动力学。预测 loss 降低不证明疾病/MI 分类好；时频表征接近也不证明丢弃相位合理。大量通用时序归一化会去掉幅度尺度，这对可靠性或疾病判断可能重要。

## 6. 用什么提前检验跨领域模型

先定义合法的分层核验包，不预先下载全量或混进比赛训练：

| 包 | 内容 | 核验问题 | 不能据此宣称 |
|---|---|---|---|
| 通用分类表征 | 合法 UCR/UEA 小规模任务候选 | TS2Vec/PatchTST/MOMENT 特征到分类头的接口和迁移方式 | 通用时序分类好就一定能解码 EEG |
| 多变量/缺失输入 | 合法多传感器样例或已有数据 | 变量顺序、缺失通道、可变数量和序列长度 | 无物理坐标的变量通用性等于 montage 泛化 |
| EEG MI 多被试 | 已有/获准 PhysioNet 或官方样例 | 原波形、事件、空间交互与跨人泛化 | 单人高分或随机窗口划分证明通用迁移 |
| 长记录与节律 | 合法睡眠/长记录样例 | 多尺度、聚合、谱目标是否有效 | 睡眠收益能推广到所有七赛道 |
| 相位/事件 | 合法 SSVEP/ERP 小样例 | patch、滤波、谱图转换是否损失关键线索 | 只看幅度谱就满足所有刺激解码 |
| 流式边界 | 同记录的有序块、分段与新记录起点 | 状态 reset、无未来输入、批/流预测一致性 | 部分因果模块使完整系统天然在线 |

通用数据首先是工程/方法诊断包，与比赛数据账本分开。外部数据能否训练学生由规则决定。确认本地通用模型接口后，仍需在合法 EEG 跨被试协议比较，不能以其他领域论文成绩替代。

| D9–D10 | A0/A1/A2 最小对照，触发式 A3–A7 验证 | 场景×候选×证据矩阵；教师×任务迁移表 |

准备执行的最小矩阵：相同学生 scratch/self-supervised；单 EEG 教师；单时序教师；双教师等权；按任务固定加权。动态门控只在双教师互补与逐样本差异有证据后进入，视觉教师再作为额外独立实验。完整 MTDP 原协议复现另行记录。

先看被冻结协议上的迁移及资源，后看“模型新不新”。放弃某预案的理由可包括：权限不允许、教师没有收益、内核不支持目标环境、phase-sensitive 任务受损、预算不合适、共享模块足够而专家没有必要。保留文献和失败分析，不保留过时运行路径。

# 脑电大模型基础说明

本文档是项目的第一份共识文档。后续所有训练、实验和汇报都应回到这里检查：我们到底在训练什么，为什么训练，怎样判断它有价值。

## 1. 项目定位

脑电大模型不是把语言大模型直接搬到 EEG 上，而是训练一个能够从多来源 EEG 中学习通用表征的基础模型。

第一阶段目标：

- 模型规模：约 10M 参数。
- 模型类型：EEG self-supervised encoder。
- 训练方式：masked channel-time reconstruction。
- 主要用途：给下游 BCI 任务提供可迁移特征。

## 2. 第一版不追求什么

- 不追求 50M、100M 以上的大参数量。
- 不追求一开始覆盖所有脑信号模态。
- 不把高分作为唯一目标，必须同时看泛化和可复现。
- 不用重叠窗口或错误切分制造虚高结果。
- 不在数据许可、隐私、被试切分不清楚时开始训练。

## 3. 目标任务

第一阶段优先覆盖：

| 任务 | 作用 |
| --- | --- |
| 运动想象 / 运动执行 | 服务机器人控制和康复 BCI |
| SSVEP | 服务稳定实时控制 |
| 情绪 EEG | 服务情绪识别比赛和认知状态分析 |
| ERP/P300 | 服务事件相关脑电识别 |
| Resting-state EEG | 提供无标签预训练数据来源 |

## 4. 第一版模型共识

推荐架构：

```text
channel-time patch Transformer encoder
```

默认输入：

```text
32 通道
4 秒
200 Hz
1 秒 patch
128 tokens
```

默认主干：

```text
d_model = 256
depth = 8
num_heads = 8
encoder 参数约 7M
训练总参数约 9M-11M
```

## 5. 数据原则

数据比模型更重要。每个数据源必须记录：

```text
数据集名称
任务类型
被试数量
session 数量
通道名
采样率
有效时长
标签
许可证
是否含隐私或医学敏感信息
预处理状态
```

训练、验证、测试切分必须优先按 subject 或 session 切分，不能简单把所有 trial 打乱。

## 6. 评估原则

必须同时报告：

- within-subject。
- cross-subject。
- leave-one-subject-out。
- frozen linear probe。
- full fine-tuning。
- few-shot subject adaptation。

必须对比 baseline：

- FBCSP-LDA。
- Riemannian tangent space。
- EEGNet。
- MiniRocket 或简单 CNN/TCN。

## 7. 训练启动条件

只有当 `训练前问题清单.md` 中 P0 和 P1 问题都完成后，才能启动正式预训练。

允许提前做的事情：

- 数据统计。
- loader smoke test。
- 10 分钟以内的小规模 overfit test。
- 单 batch 前向/反向检查。
- baseline 跑通。

不允许提前做的事情：

- 长时间正式预训练。
- 发布模型结论。
- 把未审查许可的数据混入训练集。
- 用含有测试被试的数据做预训练后再宣称跨被试泛化。

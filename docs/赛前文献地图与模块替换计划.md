# 赛前文献地图、模块替换与准备计划

本文保留2026-10-10文献阶段记录；其中“本轮不写代码/训练”只描述当时阶段。当前用户已授权直接研发，69个真实研究运行及设计限制以reports/基础模型直接研发验收.md为准。论文完整复现仍未验收，旧BSG原型不再作为执行入口。

更新：2026-10-10。范围：公开文献检索、架构分析、准备工作和后续实验设计。本轮不编写模型代码，不训练，不安装依赖，不下载完整数据集或权重。

## 1. 建议先做什么

沿用已有 M01–M12 分工，围绕一个共享 EEG 编码器准备方案。先冻结评测与输入接口，再准备小型时空编码器、独立预训练目标、独立任务头的最小闭环。现有 BSG 原型保留为候选对照，尚不能据此确定比赛主模型。

优先研究三个可单独验证的方向：真实电极位置编码、时空结构化掩码、预测目标。然后考虑 EMA 潜在表征预测和通道统一。VQ tokenizer、Mamba、长期记忆需要更多预算或接口变化，先做可行性分析。

必须区分两条路线：

- 官方权重适配：保持预训练输入和主体结构，比较线性探测、部分解冻、全量微调及允许的适配器。
- 从零预训练：可以改变内部模块，但必须重新训练并与同条件基线比较。是否允许公开数据、公开权重、无标签测试接触，以正式赛规为准。

海报信息与正式规则分开记录。OmniEEG-Bench 论文的六类任务与海报的七个赛道不是同一层级，不能据论文替代比赛数据清单或评分规则。

## 3. 主要架构：具体能借用什么

### CBraMod：优先作为架构参考

路径：每通道时间 patch -> 时间卷积分支与 rFFT 幅度分支相加 -> ACPE -> 交叉空间/时间注意力 -> 波形重建头或任务头。

官方代码的空间与时间注意力分别作用于部分特征维度，联合建模通道和时间。ACPE 是通道索引与时间网格上的深度卷积，不是物理电极坐标编码，也不保证通道重排等变。原代码在输入波形上做遮蔽，避免频谱分支看到被遮蔽内容。下游 flatten+MLP 的尺寸需要随任务设定，不能自动支持任意长度和通道数。

可借用：时频双分支、分解时空交互、重建基准。新建小型模型可单独更换位置模块或目标；直接修改官方权重的 ACPE/tokenizer 则不能假定保留原预训练能力。

### EEGPT：优先作为微调与自监督目标参考

路径：通道时间 patch 与身份位置 -> 层次化空间/时间表征 -> predictor/reconstructor -> 表征对齐与重建 -> 冻结特征或下游适配。

官方配置存在 encoder/predictor/reconstructor 的分离，可用于设计独立 objective。README 中常用输入是 58 通道、256 Hz、4 秒、64 点 patch，即 0.25 秒；不是现有项目的 0.5 秒输入。完整训练机制仍需精读，不能将其简化成随意相加的两个损失。

可借用：冻结探测与轻量适配流程；准备同主干的表征目标对照。适配官方权重时先核对通道词表、patch 和任务接口。

### LaBraM：离散 tokenizer 路线，后置完整复现

路径：通道 patch -> 频谱训练的 VQ 神经 tokenizer -> 离散 token 目标 -> 掩码代码预测 Transformer -> 任务头。

它改变的是预测对象，而非只给原波形 MSE 添加一个正则。tokenizer 与主干需要分阶段训练；官方 README 给出的 tokenizer 训练配方使用多卡，不能据此说单卡绝对不能跑，但本机完整同规模复现没有预算依据。

可借用：频谱监督、离散目标的思想。第一轮用固定连续频谱目标检验必要性；有证据和资源后再决定是否引入 VQ。

### REVE：优先研究位置与块掩码

路径：线性 patch embedding -> 3D 电极坐标与时间的 Fourier 4D 编码 -> Transformer -> 时空块遮蔽与 MAE 解码 -> 任务表征。

方法章节用真实坐标生成位置特征，并对电极坐标做扰动；空间邻域与时间跨度决定块掩码。可变输入的能力依赖正确元数据、掩码及聚合实现，不由“加坐标”自动保证。没有实测支持把论文的 60,000 小时训练规模搬到本机。

可借用：电极坐标编码和时空块掩码，但先分别比较；头大小、时间尺度与坐标单位均需明确。

### LUNA：通道统一改变了模型契约

路径：时间卷积与频谱幅度/相位 -> 电极 3D 位置 -> 学习查询跨通道注意力 -> 固定 Q 个潜在通道 -> 时间 Transformer/RoPE -> 重建或查询池化任务头。

原始通道数 C 被映射到潜在查询数 Q，适合异构布局，但输出不再是原电极网格。重建原通道需要电极查询或明确的回映射，不能直接把 Q 当 C 接旧头。原文档的下游划分不全等同于我们的跨被试协议。

可借用：只有异构通道确实成为障碍时再加入通道统一。先定义 `[B,Q,P,D]` 与原通道目标之间的解码接口。

### BSG：现有原型需要正确定位

原论文路径：平衡符号 Laplacian -> 符号相似变换 -> Lanczos 近似理想低通图滤波，学习截止频率 -> 类别特定去噪器 -> 按重建误差判别癫痫类别。

当前原型是图传播加时间卷积的启发式实现，没有完整 Lanczos、离散可逆符号变换与原分类规则，不能称原论文复现。它的通道 embedding 按数组位置索引、masked pooling、无效节点传播及 mask 覆盖位置等已在整体设计文档列为待修复项。本轮没有改代码。

可借用：作为轻量候选对照；只有按原论文理论与实现核验后，才引用其滤波保证。低参数量不证明通用表征能力。

## 5. M06 子模块及替换可行性

共享基础接口建议：

```text
输入：eeg[B,C,T]，采样率，真实 channel_id / coords[B,C,3]
      valid_channel[B,C]，valid_time 或 valid_patch，任务元数据
patch：content[B,C,P,D]，每个 patch 的时间和有效采样数
位置：content 经预训练遮蔽后，再加电极/时间位置
编码：features[B,C,P,D]，valid_token[B,C,P]
分支：独立 pretrain decoder / pooling / task head
```

输入 padding、坏道与自监督遮蔽是三类不同状态。无效位置不能参与 attention、损失或 pooling；被预训练遮蔽的位置保留坐标，且只有原本有效的目标才参与重建。全无效输入必须明确拒绝或按官方契约处理。边界 patch 不默默丢弃有效尾部。

| 子模块 | 近期候选 / 参考 | 能否替换 | 代价与条件 | 顺序 |
|---|---|---|---|---|
| 波形/频谱 tokenizer | CBraMod 双分支；BIOT STFT；LaBraM/MSBraM VQ | 从零训练可；已有权重通常不直接兼容 | 频谱分支不能看到遮蔽目标；VQ 需额外训练与码本诊断 | 简单 patch 先用，双分支随后，VQ 后置 |
| 通道/空间编码 | REVE 4D；LUNA 坐标；SPERA 球面偏置 | 可独立替换位置或 attention bias | 坐标单位、坐标系和缺失率；双极导联不是单电极点 | 高优先级 |
| 时间编码 | EEGPT 层次；LUNA RoPE | 可，但要核对绝对时间/patch 尺度 | 改 patch 时长会改变时间语义，不能只对齐 tensor 大小 | 与输入规范一起准备 |
| 空间交互 | CBraMod 空间注意力；LUNA 潜在查询；CortexBridge | 空间注意力较易；潜在通道需改接口 | C->Q 后重建和任务头都需设计，不能原样接图传播 | 中优先级 |
| 时间主干 | 分解注意力；LuMamba；NeurDuo 记忆 | 可新建，不是既有 checkpoint 的直接替换 | Mamba 内核、双向/因果语义；记忆的记录边界和 reset | 先 attention，长序列有瓶颈再换 |
| pooling / 任务头 | EEGPT 冻结探测；LUNA 查询池化 | 通常最容易独立更换 | 以有效 token 计数；记录/被试标签须先聚合再计分 | 首轮必备 |

通道重排检查要求同时重排信号、坐标、身份和 mask。若目标是布局等变，整个空间模块都需满足；仅替换 embedding 而保留按通道索引的卷积不够。

替换预训练模块时，tensor shape 相同不等于语义兼容。不能用宽松加载忽略大量缺失权重，再声称使用完整预训练模型。新增任务头可随机初始化并单独记录；新增适配器需要训练；替换 tokenizer/位置/主干需给出重新训练或对齐方案。

## 6. M07/M09/M11：最值得检验的创新

### 掩码几何：第一项低接口代价的消融

在相同主干、目标、数据、实际被遮蔽 token 比例下，比较随机 patch、连续时间块、空间邻域块、联合时空块。用明确时间跨度和空间尺度描述，记录重叠后的实际比例，避免把任务难度差异误称几何收益。不要照搬论文“最佳半径”到不同坐标单位与电极密度。

### 频谱目标：第二项低接口代价的消融

保持 tokenizer 和主干不动，先比较波形 MSE 与固定对数频带功率目标。SpecBraM 的核心不是 raw+band 混合损失；其方法还使用 SIGReg，各因素必须分开登记。文章主设定用固定窄带滤波器，并不严格等同于标准 delta/theta/alpha/beta/gamma 积分；原文的标准频带 FFT 变体可作为另一候选。

本项目先设计可解释的固定 FFT 频带目标，属于方法适配，不是宣称精确复刻其滤波器。频带、窗函数、能量归一化、log epsilon 必须冻结。目标滤波应局限于合法目标范围，避免跨划分或把近邻真实内容泄入可见输入。

睡眠优先；MI 不预设有效，SSVEP/ERP/自然刺激需要检查相位、谐波和瞬态。增加一个高频谱信息的手工特征对照，辨别是否只是回收简单功率特征。若 tokenizer 与目标都改，必须做 tokenizer×target 的 2×2 对照才能归因。

### EMA 潜在目标：有条件进入第二轮

EEG-JEPA 的教师网络不反传梯度，但增加参数副本、全输入前向和 predictor 成本。先固定掩码，比较输入空间目标与潜在空间目标，随后才比较多尺度/多层监督。记录 target stop-gradient、EMA 日程、初始化及特征方差/协方差；近期掩码论文还提示 bias-inflation collapse，不能只看 loss 下降或一个标准方差检测。

### 适配与推理：不改变科学问题

微调先比较冻结线性探测、最后若干块解冻、全量微调；如果预算限制明确，再加 LoRA。低秩参数少不保证总显存或耗时一定更少。目标被试的有标签校准必须作为 few-shot 条件单独报告，不能计为零样本跨被试成绩。

ZIPBrain token 合并、量化、记忆等优化留到确实触及推理预算后。它们可能改变预测与网格对应；任何加速候选都需重新验证官方指标、mask 与输出顺序。双向 Mamba 可做离线建模，不可据此宣称零未来信息的流式推理。

## 9. 后续首轮实验矩阵：现在设计，之后执行

资源上限先由实测确定。既有 RTX 4060 Laptop 约 8 GB 是历史记录，本轮未重新测量；参数少不等于激活、attention、EMA 和优化器状态能装入显存。先用可变通道的小型分解时空编码器做候选，深度、宽度、batch 不预先当作最终规格。

| ID | 目的 | 相对对照只改变什么 | 主要判据 |
|---|---|---|---|
| E0 | 正确性与必要性 | 标签核验、合理传统方法/EEGNet、相同编码器 scratch | 输入/梯度/划分正确；监督与简单对照能够端到端评估 |
| E1 | 验证跨布局收益 | 通道身份编码 vs 坐标位置；其余固定 | 原布局与合法缺道/重排条件下的验证指标及成本 |
| E2 | 验证重建难度设计 | 随机 vs 时间/空间/联合块 mask，实际比例匹配 | 相同有效目标量与预算，迁移而非仅重建 loss |
| E3 | 验证预测对象 | raw waveform vs 固定 band-power；其余固定 | 睡眠收益，MI/相位任务是否受损；手工频谱对照 |
| E4 | 验证潜在目标 | 固定主干和 mask 引入 EMA/predictor | 冻结迁移、坍塌诊断、峰值显存和吞吐 |
| E5，可选 | 验证通道统一 | 增加 LUNA 风格 Q 潜在通道 | 多 montage 泛化和 C->Q 解码正确性；收益是否值得成本 |
| A0 | 官方权重适配 | 冻结/部分解冻/全量/LoRA，同支持集 | 同预算、同数据的指标、训练参数量和资源 |

E1–E4 第一轮均从相同基础条件分支，不把不同主干、语料和训练时间的结果混为一个消融。确认单项有效后再检查组合及交互；未确认的模块不叠加。原论文严格复现另建记录，不与缩小模型、统一协议的方法适配混称。

预算公平性分别报告：固定数据/更新步数控制方法因素，固定 GPU 时间回答实际竞赛预算下的可用性；二者不一定能同时严格相等。先单种子做工程检查，结论性候选用匹配种子与被试级配对统计，数目依据预算和不确定性需求预先规定。最终测试只用于冻结候选的评估。

停止条件：输入/标签/分组错误先修正；超预算先缩小已定义范围；没有跨被试迁移收益不扩大预训练；只提升重建、不提升下游时检查目标捷径；一项收益不稳定就记录负结果，不能用多项同时替换掩盖问题。
